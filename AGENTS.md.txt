# AGENTS.md

# Sistema de Gestión Administrativa y Control de Ayudas Sociales
## Club de Leones de San Ramón

## Objetivo del Proyecto

Desarrollar una aplicación web para la gestión administrativa del Club de Leones de San Ramón.

El sistema permitirá administrar:

- Beneficiarios
- Ayudas sociales
- Donaciones
- Campañas
- Actividades
- Voluntarios
- Usuarios
- Reportes

El objetivo principal es centralizar toda la información en una única plataforma, reemplazando los procesos manuales.

---

# Arquitectura

Utilizar siempre una arquitectura limpia y modular.

Frontend
    React + TypeScript + Vite

Backend
    ASP.NET Core Web API (.NET 9)

Base de datos
    PostgreSQL

ORM
    Entity Framework Core

Autenticación
    JWT + Roles

Comunicación
    REST API

Utilizar PostgreSQL.

Nunca utilizar MongoDB.

Todas las relaciones deben modelarse correctamente mediante claves primarias y foráneas.

Evitar columnas redundantes.

Aplicar normalización hasta 3FN cuando sea posible.

# Seguridad

Toda petición debe validar autenticación.

Nunca confiar en validaciones del Frontend.

Validar siempre en Backend.

Las contraseñas deben almacenarse únicamente mediante hash BCrypt.

# Flujo de Trabajo

Para cualquier nueva funcionalidad seguir este orden:

1. Analizar requerimientos.

2. Diseñar modelo de datos.

3. Crear entidades.

4. Crear migraciones.

5. Crear DTOs.

6. Crear servicios.

7. Crear endpoints.

8. Crear componentes React.

9. Consumir API.

10. Validar funcionalidad.

11. Probar.

12. Documentar.

Nunca comenzar por la interfaz si el modelo de datos no está definido.

---

# Restricciones

No agregar dependencias innecesarias.

No sobreingenierizar soluciones.

Mantener el proyecto simple.

Toda funcionalidad debe responder a un requerimiento real del Club de Leones.
